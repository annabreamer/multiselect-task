# Multiselect React Component

A simple multiselect dropdown component built with React.  
It allows users to select multiple options, filter them via input, and remove selections individually or all at once.

## Getting Started

### 1. Install dependencies

```bash
npm install
```

### 2. Start the development server

```bash
npm start
```

The app will be available at [http://localhost:3000](http://localhost:3000).

### 3. Build for production

```bash
npm run build
```

This will generate the production-ready files in the `build/` folder.
